Flag di costruzione & combinazioni di grafo

Fusione dei due studi: per ogni tool, tutte le flag di costruzione con le colonne del catalogo flag (In uso · Tipo · Default · Range) affiancate a quelle del conteggio combinazioni (Effetto · Leva · Regimi · Grafi · Bench), più tutte le raccomandazioni e i conteggi.

Come leggere. Ogni riga è una flag di costruzione (elenco completo del catalogo flag). Le colonne blu vengono dal catalogo; le colonne viola dallo studio combinazioni e sono compilate solo per le flag che il conteggio considera (altrimenti —). Effetto: structure (conta per i grafi) · timing · output. In uso = passata da un comando reale del repo (Y/N). Continue discretizzate in 3 regimi. Input fisso: sotto ogni tool il tipo accettato. N_qual = modalità strutturali; N_disc = con i 3 regimi; Bench = set eseguibile.

In uso vs Bench — non sono la stessa cosa. In uso descrive lo stato attuale del repo (la flag è passata da un comando reale, sì/no). Bench è prescrittivo: indica se la flag andrebbe variata nello studio di benchmark. Divergono nei due sensi: una leva di risorsa/output può essere Y in uso ma N in bench (es. --maxCores, --gfa: passate ma non cambiano il grafo); una leva structure lasciata a default può essere N in uso ma Y in bench (es. --maskMode, --clip: da esplorare proprio perché cambiano il grafo).
